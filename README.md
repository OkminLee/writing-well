# writing-well

Claude Code 스킬 + 서브에이전트. William Zinsser의 『On Writing Well』 방법론으로 산문을 쓰고 고친다.

> A Claude Code skill and subagent that drafts and revises prose using the method from William Zinsser's *On Writing Well*. Rules are written in Korean; the underlying principles are language-agnostic.

---

## 왜 만들었나

같은 과제("SOXL 자동매매 봇 6개월 운영기를 900자로")를 스킬 없이 세 번 돌렸더니 세 번 다 같은 글이 나왔다.

- 첫 문장이 주제를 다시 말한다 — "…봇을 6개월 돌리면서 가장 크게 배운 건"
- 본문이 **첫째·둘째·셋째**로 갈린다
- 마지막 문단이 **"결국"**으로 시작해 이미 한 말을 압축한다
- 숫자도 이름도 날짜도 없다. 사람이 한 명도 안 나온다

세 편의 마지막 문장은 사실상 같은 문장이었다. 이건 재능 문제가 아니라 **결정을 안 한 문제**다. 이 스킬은 그 결정들의 순서다.

## 쓰는 법

**스킬** — 글을 쓰거나 고칠 때 자동으로 걸린다. 직접 부르려면 `/writing-well`.

**에이전트** — 글 자체가 산출물일 때 위임한다. 세 모드로 갈린다.

| 모드 | 언제 | 산출물 |
|---|---|---|
| `WRITE` | "~에 대해 써줘" | 완성된 글 |
| `REVISE` | "이 글 고쳐줘" | 고친 글 + 무엇을 왜 바꿨나 + 손대지 않은 것 |
| `STRUCTURE` | "구조 먼저 잡아줘" | 6개 결정 + 뼈대 + 리드/엔딩 후보 (본문 안 씀) |

## 무엇이 들어 있나

`skills/writing-well/SKILL.md` — 계약. 재료 게이트 → 쓰기 전 6개 결정 → 글의 모양 → 반드시 채우는 슬롯 → 3회 통과 → 생각쓰기.

`skills/writing-well/references/rewrite-pass.md` — 교정 실무. 구조부터 보고, 의미의 보풀을 걷고, 대괄호로 가지를 치고, 소리 내어 읽는다. 한국어 완충어·긴말/짧은말·개념명사 뒤집기 목록 포함.

`agents/writing-well.md` — 서브에이전트 정의.

## 재료 게이트

이 스킬에서 가장 중요한 규칙은 문장 규칙이 아니다.

초판에는 "검증 가능한 구체 3개 이상"이라는 슬롯만 있었다. 그랬더니 재료를 하나도 안 준 과제에서 세 번 다 수익률과 날짜와 체결 수량을 지어냈고, 세 번 다 **"친구가 물었다"**라는 없던 대화로 사람 슬롯을 채웠다. 슬롯이 신뢰성을 이긴 것이다.

그래서 재료 게이트를 슬롯보다 위에 놨다. 금지만으로는 "글만 출력하라"는 지시에 지므로, 날조 대신 **합법적 경로**를 준다.

```
[N%] 빠진 날, 나는 아무것도 하지 않았다. [날짜?], 봇은 이미 [N주?]를 사들인 뒤였다.

## 채워야 할 것
- [ ] 그날 낙폭과 날짜
- [ ] 실제 체결 수량
```

글의 모양은 완성하되 구체 자리는 비워 표시한다. 신뢰성은 대통령의 그것만큼 부서지기 쉽다.

## 계측

같은 과제를 반복 실행하고 기계로 셌다.

| 실패 모드 | 스킬 없음 | v1 | v2 |
|---|---|---|---|
| 첫째/둘째/셋째 리스티클 | 3/3 | 0/3 | 0/2 |
| 주제 재진술 리드 | 3/3 | 0/3 | 0/2 |
| "결국/정리하면" 요약 엔딩 | 3/3 | 0/3 | 0/2 |
| 구체 날조 | — | 3/3 | 0/2 |

재료를 준 실행에서는 출력에 등장한 숫자 토큰 전부가 재료에 실재했다. 미출처 0건.

## 들어 있지 않은 것

이 저장소에는 책의 장별 요약이 없다. 로컬 작업본에는 4부 24장을 정독해 만든 4.3만 단어 노트(`references/01`~`04`)가 있지만 원문 인용과 구성을 그대로 따르므로 **재배포하지 않는다.**

SKILL.md와 `rewrite-pass.md`만으로 스킬은 완결적으로 동작한다. 더 깊이 가려면 책을 읽어라 — William Zinsser, *On Writing Well*, 6th ed. (HarperCollins, 2001).
