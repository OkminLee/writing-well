# writing-well

William Zinsser 『On Writing Well』의 방법으로 산문을 쓰고 고치는 Claude Code 스킬 + 서브에이전트.

> A Claude Code skill and subagent that drafts and revises prose using William Zinsser's method. The rules are written in Korean; the principles aren't.

---

## 고치기 전과 후

### 필자 머릿속에만 있던 고리

| | |
|---|---|
| **before** | 매일 30분씩 걸었는데 체중은 그대로였다. |
| **after** | 매일 30분씩 걸었는데 체중은 그대로였다. **걷고 오면 배가 고파서 저녁을 한 그릇 더 먹었다.** |

before의 문장은 문법이 멀쩡하고 사실도 맞다. 그런데 읽는 사람은 왜 그랬는지 모른다. 연결이 필자 머릿속에만 있었기 때문이다. 맞춤법 검사기는 이걸 못 잡는다. "더 매끄럽게 고쳐줘"도 못 잡는다. 문장마다 **앞 문장에서 독자를 어디에 두고 왔는지** 묻는 통과만 잡는다.

### 사람도 동사도 없는 문장

| | |
|---|---|
| **before** | 팀 간 소통 활성화의 필요성이 이번 프로젝트의 가장 큰 교훈이었다. |
| **after** | 우리는 목요일까지 서로가 뭘 만들고 있는지 몰랐다. |

주어가 중요성·필요성·활용·개선 같은 개념명사면 뒤집는다. 완충어(좀·다소·사실상)와 가치 선언어(놀랍게도·물론)는 지운다. **약간 대담하지 마라. 대담하라.**

## 재료에 없는 것은 쓰지 않는다

"우리 독서모임 반년 후기 좀 써줘"에 딸려온 재료가 이게 전부라고 하자.

```
- 3월에 시작
- 사람은 꾸준히 왔는데 몇 명인지는 안 셌음
```

| | |
|---|---|
| **스킬 없이** | 첫 모임에 4명이 왔고 반년 만에 17명이 됐다. 한 참가자는 "인생이 바뀌었다"고 했다. |
| **writing-well** | 3월에 독서모임을 시작했다. 사람은 꾸준히 왔다. `[인원 추이?]` |

`4명`도 `17명`도 재료에 없다. 그 참가자는 아무 말도 한 적이 없다. 그런데 위쪽이 훨씬 잘 읽힌다 — 그래서 지어낸다. 대신 스킬은 글 끝에 이걸 붙인다.

```
## 채워야 할 것
- [ ] 첫 모임과 지금의 실제 인원
- [ ] 누가 뭐라고 했는지 (있었다면)
```

글의 모양은 완성하되 구체가 들어갈 자리는 비워 표시한다. "검증 가능한 구체 3개 이상"이라는 자기 요구를 채우려고 숫자를 지어내면 구체 세 개를 얻고 글 전체를 잃는다. 없던 대화를 인용으로 만드는 순간 그 글은 실패다. 실재하는 인용도 원문과 한 글자씩 대조한다 — 인용부호 안이 틀리면 그 뒤의 주장까지 의심받는다.

이 규칙이 저장소의 다른 모든 규칙 위에 있다.

## 글 한 편을 통째로

사실 두 개만 쥐고 칼럼 한 편을 쓴 다음, 같은 주제에 스킬을 걸었다. **7문단 688자 → 5문단 362자 (−47%).**

**리드**

| | |
|---|---|
| **before** | 일상에서 우리가 무심코 누르는 버튼들 중 상당수가 실제로는 아무 기능을 하지 않는다는 사실은 꽤 흥미로운 이야기다. |
| **after** | 뉴욕시 횡단보도 버튼 3,250개 가운데 2,500개 이상은 아무 데도 연결돼 있지 않다. |

**엔딩**

| | |
|---|---|
| **before** | 결국 위약 버튼은 기술과 인간 심리가 만나는 지점을 잘 보여주는 사례라고 할 수 있다. |
| **after** | 같은 기사에서 심리학자 엘런 랭어는 이렇게 말했다. "통제하고 있다는 느낌은 대단히 중요합니다. 스트레스를 줄이고 안녕감을 높이죠." |

**그런데 정작 크게 바뀐 건 문장이 아니었다.** 통과 1에서 이 문장이 걸렸다 — "심리학 연구들은 사람이 상황을 통제할 수 있다고 느낄 때 스트레스가 감소한다는 점을 일관되게 보여준다." 연구도 저자도 연도도 없다.

지우면 글이 얇아지고, 두면 글이 거짓이 된다. 그래서 찾아봤고, 같은 2004년 기사 안에 실명 발언이 있었다. 초고 일곱 문단에 사람이 한 명도 없었다는 것도 그때 드러났다. 엔딩이 바뀐 건 표현을 고쳐서가 아니라 **없던 재료를 캐 왔기 때문**이다.

전문과 변경 근거는 **[examples/placebo-buttons.md](examples/placebo-buttons.md)**.

## 쓰는 법

**스킬** — 글을 쓰거나 고칠 때 알아서 걸린다. 직접 부르려면 `/writing-well`.

**에이전트** — 글 자체가 산출물일 때 위임한다. 요청 문구로 모드가 갈린다.

| 요청 | 모드 | 산출물 |
|---|---|---|
| "~에 대해 써줘" | `WRITE` | 완성된 글 |
| "이 글 고쳐줘" | `REVISE` | 고친 글 + 무엇을 왜 바꿨나 + 손대지 않은 것 |
| "구조 먼저 잡아줘" | `STRUCTURE` | 6개 결정 + 뼈대 + 리드·엔딩 후보 (본문은 안 씀) |

어느 모드로 가든 순서는 고정이다. **재료 게이트** → **쓰기 전 6개 결정**(축소·요점·자격·톤·리드 재료·엔딩 재료) → **리드·본문·엔딩** → **3회 통과**(의미·가지치기·소리). 가지치기에서 초고가 30~50% 줄지 않았으면 통과를 안 한 것이다.
